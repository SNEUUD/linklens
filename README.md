# LinkLens (nom provisoire)

App macOS pour photographes débutants (tri des photos par IA locale, import, export) et pages web de livraison aux clients.

- `macos/` : app macOS (Swift 6, SwiftUI, SwiftData)
- `web/` : Next.js, pages publiques et API
- `api/openapi.yaml` : contrat d'API, source unique de vérité
